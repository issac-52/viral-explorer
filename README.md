# 엑싯바이럴 · ExitViral

한국어·일본어·영어 후기에서 협찬 고지와 관련된 문구를 찾아 원문 그대로 표시하는 첫 개발 버전입니다. 표시 언어와 분석 대상 언어는 독립적입니다. 현재는 직접 붙여넣은 텍스트와 명시적인 표현 규칙을 사용합니다. URL 수집과 AI 문맥 분석은 다음 개발 범위입니다.

## 로컬 실행

Node.js 24 및 npm 환경에서 실행합니다.

```sh
npm ci
npm test
npm run dev
```

표시된 로컬 주소(기본 http://localhost:8787)를 엽니다. dev 명령이 TypeScript 검사, Vite 빌드 및 로컬 D1 마이그레이션을 수행합니다. 프런트엔드 변경 후에는 다시 빌드하세요. Cloudflare 계정이나 유료 API 키 없이 로컬에서 실행됩니다.

## API

- POST /api/analyses — JSON 본문 `{"text":"후기 내용"}`. 최대 20,000 UTF-16 코드 단위. 최초 저장 시 201, 재사용 시 200.
- GET /api/analyses/{id} — 저장된 ID와 인용 문구 배열을 반환합니다. 결과 주소를 가진 사람은 인용 문구를 열람할 수 있습니다.

D1에는 원문 전체 대신 규칙 버전을 포함한 본문 해시, 임의 결과 ID, 일치한 표현과 생성 시각을 저장합니다. 광고 여부 확률을 산출하지 않습니다. wrangler.jsonc의 데이터베이스 UUID는 로컬 개발용입니다. 운영 배포에는 실제 D1 연결, 원격 마이그레이션 및 요청량 제한 설정이 필요합니다.
